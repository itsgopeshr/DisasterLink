IoT-Based Smart
Disaster Network.

A low-cost, two-node IoT communication prototype using ESP32 and SX1278 LoRa modules to transport emergency environmental telemetry when conventional Internet fails.

📡 OPEN RESCUE DASHBOARD

System Architecture

1️⃣

Field Node (Sense)

An ESP32 equipped with a water-level sensor monitors the environment. When a flood threshold is crossed, it packages the data.

2️⃣

LoRa Link (Transmit)

The SX1278/RA-02 module transmits compact point-to-point packets over long distances without needing cellular infrastructure.

3️⃣

Rescue Node (Display)

The receiving node validates the packet, sends an ACK, and forwards serial data to this dashboard for responders.
